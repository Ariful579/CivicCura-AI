Project Name: CivicCura
Tagline: AI-Powered Offline Retinal Diagnostic Network for Primary Screening

Problem:
Diabetic retinopathy leads to preventable blindness, but 80%+ of cases occur in low-resource settings lacking $10,000+ fundus cameras, stable internet, and specialized ophthalmologists.

Solution:
CivicCura is an offline-first AI diagnostic system running locally on standard PCs. Paired with low-cost smartphone optical adapters (~$30), it provides zero-latency primary screening, visual risk alerts, and downloadable PDF medical reports without requiring cloud connectivity or internet access.

Key Technical Highlights:
- Engine: MobileNetV2 architecture trained on the APTOS 2019 dataset.
- Stack: Python 3.13, TensorFlow, Streamlit, ReportLab (PDF generator).
- Deployment: 100% offline local inference with single-click batch deployment.
